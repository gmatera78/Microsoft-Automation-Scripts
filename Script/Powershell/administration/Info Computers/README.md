\# Administration Scripts



\## Info\_ADComputers.ps1



Exports detailed Active Directory computer information to a CSV file.



\### Purpose

Used for inventory, auditing, and reporting of AD computer objects.



\### Output

CSV file containing:

\- Computer name

\- Operating system and version

\- Account status

\- OU path

\- Creation and modification dates

\- Last logon information

\- Password last set

\- Kerberos encryption types



\### Requirements

\- ActiveDirectory PowerShell module

\- Domain connectivity

\- Appropriate permissions
